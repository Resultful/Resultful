# 8. The dependency-free release is `0.3.0-beta01`

Proposed: [decision 1](0001-core-is-dependency-free.md) breaks source compatibility (`OneOf.Types.None` becomes
`Resultful.None`; `ToOneOf` moves to another package), so the release is `0.3.0-beta01` rather than
`0.2.0-beta06`. Consumers pinning `0.2.0-*` are not moved onto the break by a floating range.

The non-breaking work ships first as `0.2.0-beta06` (packaging fix and sequential composition), so consumers
get the dependency fix without the break. Pull requests between the two do not change the version.
