# 8. The dependency-free release is `0.3.0-beta01`

Proposed: [decision 1](0001-core-is-dependency-free.md) breaks source compatibility (`OneOf.Types.None` becomes
`Resultful.None`; `ToOneOf` moves to another package), so the release is `0.3.0-beta01` rather than
`0.2.0-beta06`. Consumers pinning `0.2.0-*` (rig) are not moved onto the break by a floating range.

Alternative: ship milestone 1 alone as `0.2.0-beta06` first, then `0.3.0-beta01`. The maintainer chose one
pull request for everything, which makes a single `0.3.0-beta01` the simpler choice.
