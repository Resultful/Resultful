# Agent briefs

The common briefs given to implementer agents in the 2026-11-21 parallel batches. Reuse them as templates: copy
one, change the base branch, the PR rows and the ownership boundaries, and add a per-PR section (scope, tests).
Reviewer prompts followed the same shape: read-only, copy the worktree before building, judge named risks, report
ranked findings with file:line, failure scenario and fix.
