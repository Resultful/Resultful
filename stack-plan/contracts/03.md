## Done when

1. **`AnalysisLevel` `latest-all`** for `src/` (tests may stay `latest-recommended` or go further; say which). Every
   rule that fires is either fixed without changing IL, or opted out explicitly: one `<NoWarn>` entry or
   `.editorconfig` severity line per rule ID, each with a one-line reason in a comment. No blanket suppressions,
   no `#pragma` in `src/`. The opt-out list is in the PR body under `## Suppressions`.
2. **Core edits are annotations and docs only.** The IL list (`eng/il-diff-0.2.0.txt`) stays empty: `eng/il-diff.cs`
   run against the beta06 baseline reports no method whose body changed. If a fix would change IL, opt out instead.
3. **Nullable audit.** Every public signature in `src/Resultful` is checked for the right nullability (`T?`,
   `[NotNullWhen]`, `[MaybeNull]`, `[AllowNull]`, `[DisallowNull]` …) against today's runtime behaviour, which the
   characterisation suite pins. Each re-annotation of a public member is a line in `eng/api-diff-0.2.0.txt`
   (the committed, reviewed list of API differences from beta06), and `eng/api-diff.cs` reports exactly that list.
   No member is added or removed.
4. **XML docs on every public member**, written in house style (short plain sentences, what it does and when it
   fails). Docs are trivia, so IL doesn't change. CS1591 is enforced by a CI build step with
   `-p:GenerateDocumentationFile=true` that doesn't pack, so the 0.2.0 package file list stays identical to beta06
   (05 turns the XML file on in the package, in stack B).
5. **Per-target `PublicAPI` files**: `PublicAPI.Shipped.txt`/`Unshipped.txt` per target framework of `src/Resultful`
   (`netstandard2.0`, `net10.0`, `net11.0`), wired through conditional `AdditionalFiles`, so a target-only member
   shows in its own file. Fix `.ls-lint.yml` if the folder layout needs it (`| regex:api` for `src/*/api/`).
6. The `release-check` scripts from 02 run in CI against beta06 and pass with the committed lists. The counts gate
   and the suppressions gate pass. Every CI job passes.
